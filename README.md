# Exit Button - כפתור צף לניקוי session בנק

כפתור צף ("יציאה") שמופיע מעל כל מסך - כולל מעל אפליקציות הבנק ומעל Fully Kiosk.

**איך זה עובד:**
- האפליקציה רושמת ברקע כל אפליקציית בנק שנפתחה מאז הניקוי האחרון - גם אם המשתמש
  כבר יצא ממנה וחזר לקיוסק.
- **לחיצה על "יציאה"** - מריצה `pm clear` על כל האפליקציות שנרשמו (ולא על אחרות),
  וחוזרת לקיוסק.
- **חזרה לקיוסק בלי ללחוץ "יציאה" לא מנקה כלום.**
- **טיימר:** מרגע פתיחת אפליקציית הבנק הראשונה מתחילה ספירה לאחור של 5 דקות, שמוצגת
  על הכפתור. בדקה האחרונה הכפתור הופך לכתום. בסיום - ניקוי אוטומטי וחזרה לקיוסק.
- **"+3 דק'":** כפתור כחול מתחת ל"יציאה" שדוחה את הניקוי ב-3 דקות, עד פעמיים ב-session.
- Fully Kiosk לעולם לא מנוקה. הפועלים ומזרחי-טפחות מוחרגים (לא נרשמים ולא מנוקים).

כל הזמנים והרשימות ניתנים לשינוי ב-`BankConfig.kt`.

## דרישות
- **חובה root פעיל (Magisk)** על המכשיר - האפליקציה משתמשת ב-`su` כדי
  לזהות את האפליקציה בחזית ולהריץ `pm clear`. בלי root היא לא תעבוד.
- אנדרואיד 8.0 (API 26) ומעלה.

## התקנה
1. בנה APK (ראה פרק "בנייה דרך GitHub Actions" למטה, אותה שיטה כמו ב-
   KioskApp).
2. התקן את ה-APK על אותו מכשיר שבו Fully Kiosk כבר פועל.
3. פתח את האפליקציה "Exit Button" פעם אחת.
4. ייפתח מסך הגדרות עם בקשת הרשאת **"הצגה מעל אפליקציות אחרות"**
   (Display over other apps / Draw over other apps) - הפעל את המתג
   עבור Exit Button, וחזור אחורה (או פשוט סגור את מסך ההגדרות).
5. יופיע דיאלוג **Magisk Superuser** (האפליקציה משתמשת ב-root גם כדי לתת לעצמה
   הרשאת "גישה לנתוני שימוש" שמאפשרת לזהות אילו בנקים נפתחו) שמבקש הרשאת root - אשר ("Grant"),
   ועדיף לסמן "Remember choice" / "זכור את הבחירה" כדי שלא יישאל שוב.
6. יופיע כפתור אדום צף קטן בפינת המסך, שכתוב עליו "יציאה". אפשר לגרור
   אותו למיקום נוח (למשל פינה תחתית) - המיקום נשמר כל עוד השירות רץ.

## שימוש
בכל שלב (באמצע שימוש באפליקציית בנק, או מתוך מסך הקיוסק עצמו) - לחיצה
על הכפתור האדום מנקה את ה-session הנוכחי (אם זה בנק שלא הוחרג) ומחזירה
מיד למסך הקיוסק של Fully Kiosk.

## עדכון רשימת הבנקים בעתיד
כל ההגדרות נמצאות במקום אחד: `app/src/main/java/com/example/exitbutton/BankConfig.kt`.
- `CLEAR_DATA_PACKAGES` - אפליקציות שעליהן מפעילים `pm clear`.
- `SESSION_MINUTES`, `SNOOZE_MINUTES`, `MAX_SNOOZES` - הטיימר והדחיות.
- `KIOSK_PACKAGE` - שם החבילה של אפליקציית הקיוסק שאליה חוזרים.

אחרי עריכה: עשה commit ו-push ל-GitHub (או ערוך ישירות באתר), ה-Action
יבנה APK חדש אוטומטית, והתקן אותו מחדש על המכשיר (לא צריך להסיר את
הישן קודם - התקנה מחדש על גבי הקיים שומרת את ההרשאות שכבר אושרו).

## בנייה דרך GitHub Actions
אותה שיטה בדיוק כמו בפרויקט KioskApp:
1. פתח ריפוזיטורי חדש וריק ב-GitHub (למשל בשם `ExitButtonApp`).
2. שכפל (Clone) אותו למחשב עם GitHub Desktop.
3. העתק את כל תוכן התיקייה הזו (כולל `.github`, `gradle`, `gradlew`)
   לתוך התיקייה המשוכפלת.
4. ב-GitHub Desktop: Commit to main, ואז Push origin.
5. בלשונית Actions באתר GitHub, ה-build יתחיל אוטומטית וייבנה APK תוך
   כ-2 דקות. ה-APK הגמור יהיה זמין להורדה כ-Artifact בשם
   `exit-button-debug-apk`.

## אבחון תקלות
- **הכפתור לא מגיב ללחיצה** - ודא שהרשאת ה-root אושרה (בדוק ב-Magisk
  App תחת "Superuser" שהאפליקציה מופיעה שם ומסומנת כמאושרת).
- **הכפתור לא חוזר לקיוסק** - ודא ש-`KIOSK_PACKAGE` ב-`BankConfig.kt`
  תואם בדיוק לשם החבילה של Fully Kiosk במכשיר שלך (ניתן לבדוק עם
  `adb shell pm list packages | findstr -i fully`).
- **המשתמש עדיין רואה שם שמור אחרי הלחיצה** - ודא שהאפליקציה שבה
  לחצת עליה לא ברשימת `EXCLUDED_PACKAGES`, ושה-package name תואם
  בדיוק למה שמותקן במכשיר.
